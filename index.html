💾 Сохранить приложение

Данные сохраняются в браузере на этом устройстве. Для каждой карточки можно редактировать слово, перевод, пример и категорию.

Добавить карточку

При желании можно загрузить свою картинку для карточки. Это не обязательно: приложение работает и просто как словарь с переводом.
